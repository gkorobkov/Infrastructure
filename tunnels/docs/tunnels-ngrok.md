# ngrok

Создайте аккаунт и получите [authtoken](https://dashboard.ngrok.com/get-started/your-authtoken). API key предназначен для API управления аккаунтом и не заменяет authtoken клиента. Установите ngrok через предложение winget или [официальный Windows архив](https://ngrok.com/downloads/windows), распакованный в пользовательский каталог PATH.

```powershell
.\tunnels\tunnels-start-ngrok.ps1 -Port 5678 -WebhookPath /webhook/my-agent
# Собственный существующий профиль, отдельный порт инспектора
.\tunnels\tunnels-start-ngrok.ps1 -NgrokConfig "$env:LOCALAPPDATA\ngrok\ngrok.yml" -NgrokApiPort 45001
```

Скрипт проверяет конфигурацию v2/v3 без вывода её содержимого. Если профиль явно не выбран, ищет `%LOCALAPPDATA%\ngrok\ngrok.yml` и `%USERPROFILE%\.ngrok2\ngrok.yml`. Также поддерживается существующая переменная окружения `NGROK_AUTHTOKEN`. При отсутствии токена появляется скрытый запрос: введённый секрет действует только в дочернем процессе и не сохраняется на диск.

Для постоянного профиля официальная команда — `ngrok config add-authtoken <TOKEN>`. Выполняйте её самостоятельно, учитывая, что ввод может сохраниться в истории PowerShell, а токен попадёт в пользовательский конфиг. Не храните его в репозитории. Скрытый ввод скрипта позволяет избежать токена в истории и аргументах процесса.

Существующий конфиг не изменяется. Временный файл без токена задаёт только `web_addr` на loopback и объединяется с выбранным профилем. Свободный API-порт выбирается автоматически либо через `NgrokApiPort`; адрес инспектора напечатан при запуске, он не обязательно `4040`. URL берётся из `/api/tunnels` этого клиента с проверкой upstream. Откройте инспектор для просмотра запросов, учитывая, что они могут содержать личные данные. Если порт занят или перехвачен между проверкой и запуском, остановите запуск и выберите другой порт.

Скопируйте `WEBHOOK URL` из `URL RECEIVED`, затем проверьте запрос из UI. HTTPS-ответ может оказаться страницей предупреждения ngrok, а не приложением. Ctrl+C останавливает этот клиент. Условия бесплатного плана и лимиты зависят от аккаунта; проверяйте dashboard. Ошибки авторизации требуют действительного authtoken, ошибки лимитов — завершения лишних сессий или выбора Cloudflare/localtunnel. Скрипт не обходит ограничения.

Источники: [CLI](https://ngrok.com/docs/gateway/agent/cli), [конфигурация v3](https://ngrok.com/docs/gateway/agent/config/v3), [локальный API](https://ngrok.com/docs/gateway/agent/api).
